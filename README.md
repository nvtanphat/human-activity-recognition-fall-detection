# Human Activity Recognition (HAR) & Fall Detection System

A machine learning and deep learning project for classifying human activities and detecting falls using 3D smartphone accelerometer data (UniMiB-SHAR dataset).

## Project Overview

- **Activity Classification**: Classification of daily living activities (ADL) and falls using classical machine learning baselines (k-NN, SVM, Random Forest) and deep learning models (CNN, BiGRU, Attention networks) in PyTorch.
- **Real-time Prototype**: A web dashboard and API prototype built with FastAPI for simulated real-time stream inference and fall alerts.
